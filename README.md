# DSL: текущая версия для локальной проверки

- `dsl-updated.zip` — исходники приложения; установка и запуск описаны в `dsl/README.md` внутри архива.
- `dsl-test-cases.zip` — 174 сценария в CSV/Markdown/JSON, матрица свойств, результаты проверок и незакрытые пункты.
- `SHA256SUMS` — контрольные суммы архивов.

Полный pixel perfect и весь объём замечаний ещё не закрыты. Ограничения перечислены в `implementation-status.md` внутри архива тест-кейсов. Проверка реального backend выполняется локально; браузерные автотесты используют подмену API.

В архивы не включены node_modules, выходные каталоги Next.js и локальные .env с секретами.
